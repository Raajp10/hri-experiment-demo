As in PsiTurk, the experiment goes to trialdata. Demographics and all questions before and after the experiment go to questiondata. Both files use the same PsiTurk ID.

Where the real data goes. This demo runs without a server, so it keeps each session in the browser that ran it. In the study, PsiTurk's server saves every page to its database (participants.db), and scripts/backup_data.py copies the database and both CSV files to a dated backup. Participants have no way to delete data.
