# Experiment demo (participant view; Mac or any browser, nothing to install)

Open `index.html`: it starts on the consent page, exactly like the study. Each new participant is assigned a
condition the way PsiTurk does it (the least-filled condition). Turn the sound on.

- Researcher: `data.html` shows what was recorded in this browser (trialdata + questiondata, same PsiTurk ID) and
  downloads both CSV files. Nothing can be deleted.
- Researcher walk-through: add `?tools=1` to the link (`index.html?tools=1`) for the video-speed bar, and
  `&cond=1&counter=0` to pick a condition.
- Safari: if a video does not start, click **▶ Play video** once.
