# Experiment demo (Mac, no VM, nothing to install)

1. Double-click `HRI_experiment_demo.zip`, then open `HRI_experiment_demo/index.html` in Chrome or Safari.
2. Turn the sound on. In Safari, if the first video does not start, click **▶ Play video** once
   (or Safari → Settings → Websites → Auto-Play → Allow All Auto-Play).
3. Click **Start as a new participant**, or choose one of the 4 conditions. Tick **Skip to Robot 1** for a quick demo.
4. When the study ends, the **Recorded data** tab shows exactly what was saved: trialdata (experiment) and
   questiondata (demographics and questionnaires), with the same PsiTurk ID, and downloads both CSV files.

This is the real PsiTurk experiment (same pages, videos, voice). Only PsiTurk's server is replaced, and the answers
are kept in this browser.
